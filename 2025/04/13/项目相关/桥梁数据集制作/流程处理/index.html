数据处理下载流程

1. 确定灾害影响区域

根据提供的灾害数据汇总，定位灾害中心，根据属性（details）访问灾害信息网站或手动下载矢量文件（geometry）确定灾害影响的范围。

首先将损毁桥梁位置数据.csv中的 geometry 列下想要下载的地区的链接复制，粘贴到 area.txt,如下图所示：

使用download_and_convert_json2shp.py下载 json 文件并转化为 shp 文件：

2. 确定潜在的桥梁位置

该流程最为关键，也最为麻烦，可能需要通过目视的方式来确定灾害区域有没有桥梁。同时灵活的结合区域内OSM数据、谷歌地球历史高分影像数据和相关新闻报道，也可以快速的确定潜在的桥梁位置。

（1）使用 QGIS 获取 OSM 数据：

使用 QGIS 打开一个 shp 文件

（2）安装 OSM 相关插件

  • 打开 QGIS
  • 点击菜单栏的"插件" → "管理和安装插件"
  • 在搜索框中输入以下插件名称并安装：
    • QuickOSM
    • OSM Downloader
    • OSMInfo

（3）使用 QuickOSM 插件获取 OSM 数据

QuickOSM 是最常用的 OSM 数据获取插件，操作简单高效：

  1. 打开 QuickOSM

    • 点击 QGIS 菜单栏的"矢量" → "QuickOSM" → "QuickOSM"

  2. 使用快速查询获取桥梁数据

    • 在 QuickOSM 对话框中选择"快速查询"选项卡
    • 在"键"下拉菜单中选择"bridge"
    • 在"值"下拉菜单中选择"yes"（或保持为空以获取所有桥梁）
    • 在"范围"部分，可以选择：
      • "图层范围"（如果您已经加载了灾害区域的图层）
      • "绘制在画布上"（手动绘制感兴趣区域）
      • "输入坐标"（输入灾害中心坐标和半径）

    我这里只做了如下设置：

  3. 设置高级选项

    • 点击"高级"展开更多选项
    • 勾选您需要的图层类型（节点、线、多边形等）
    • 设置输出名称前缀，例如"bridge_"

  4. 运行查询

    • 点击"运行查询"按钮
    • QGIS 将从 OSM 服务器下载数据并添加到图层面板中

(这几个点和线我也没看懂)

（4）QGIS中添加卫星图像作为底图

  • 安装QuickMapServices插件

  • 点击菜单"插件" → "管理和安装插件..."

  • 搜索"QuickMapServices"并安装

  • 获取更多地图源

  • 安装完成后，点击菜单"网络" → "QuickMapServices" → "设置"

  • 切换到"更多服务"选项卡

  • 点击"获取贡献包"按钮

  • 添加卫星影像

  • 点击菜单"网络" → "QuickMapServices"

  • 选择您需要的卫星影像服务，例如：

    • Google → Google Satellite
    • Bing → Bing Satellite
    • ESRI → ESRI Satellite

4. 影像数据获取

若桥梁存在损毁情况，使用Google Earth Engine（GEE）下载灾前、灾后光学和雷达影像（GRD）。影像下载时需保证：影像云量尽可能小，达到目视可以判断；同一地区的灾前、灾后影像时间间隔尽可能接近。
